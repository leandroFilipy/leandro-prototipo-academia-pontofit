# 🏋️ Academia Pontofit

Bem-vindo ao repositório do protótipo da academia **Pontofit**! Este projeto foi desenvolvido como uma landing page/estrutura inicial para apresentar a marca, serviços e proposta da academia em um formato moderno e visualmente atrativo.

## ✨ Visão geral

O objetivo deste projeto é criar uma experiência inicial para uma academia com:

- 📣 Apresentação da marca
- 🏃‍♂️ Destaque para modalidades e benefícios
- 📍 Informações de contato e localização
- 🧩 Estrutura simples e responsiva em HTML

## 🚀 Tecnologias

- HTML5
- CSS3 (se houver estilos em arquivos separados)
- JavaScript (se houver interações dinâmicas)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/leandroFilipy/leandro-prototipo-academia-pontofit.git
```

2. Acesse a pasta do projeto:

```bash
cd leandro-prototipo-academia-pontofit
```

3. Abra o arquivo `index.html` no navegador.
